## Current Concept:
A 3D platformer metroidvania about climbing a skyscraper to prove yourself to the City. The game will have 5 distinct levels to beat: 4 levels that may be beaten in any order to gain new abilities, and a 5th final level to test the player. Your main collectables are the new abilities, currently called Styles, that give you a new platformer move to pull off (Air dash, wall run, grapple to point, etc). Every style is mapped to its own button, but must be used with the same button (ex: 1234 to switch styles, right-click to use the ability / d-pad to switch, circle to use). The game will become a balancing act of executing each style's action mid-air or in perilous situations to reach the end of the game.
